# MonostichBlog
当前目录为空，因此从零搭建一个 React + Vite 的博客 preview，不接后端、不读取远程 Git 仓库，先预留未来接入 Git 内容仓库的数据边界。

技术方案
React + Vite：作为基础前端工程。
React Router：实现主页、Blog、技术笔记、文章详情等独立页面。
Tailwind CSS：负责响应式布局、暗色终端视觉和状态样式，避免手写大量 CSS。
Lucide React：提供导航、搜索、标签、返回等图标。
本地内容数据模块：用少量 mock 数据模拟未来 Git 仓库中的 Markdown 元数据；数据字段按后续 Git 内容接入可替换的结构组织。
页面与视觉
全局壳层
深色终端/开发者风格：近黑背景、绿色/青色荧光强调色、等宽字体与细边框。
顶部导航包含 MonostichBlog 品牌、主页 / Blog / 技术笔记三个栏目、GitHub 外链。
移动端导航折叠或改为紧凑布局，所有页面保持可用。
统一实现页面标题、面包屑/状态提示、空状态和 hover/focus 状态。
主页 /
Hero 区展示 Aloha、占位个人简介、终端式欢迎语和 GitHub 链接。
展示 Blog 与技术笔记的精选入口、少量近期内容、栏目统计/状态信息。
通过明显 CTA 进入两个内容栏目。
Blog /blog
文章列表卡片：标题、摘要、日期、阅读时间、标签、来源路径等信息。
前端搜索与标签筛选；无匹配时显示友好的终端风格空状态。
内容数量保持少量，但结构足以验证筛选和响应式布局。
技术笔记 /notes
与 Blog 独立成页，结构简单区分为短条目/知识记录列表。
支持搜索和标签筛选，展示技术栈、命令/要点预览和更新时间。
详情页 /blog/:slug 与 /notes/:slug
根据本地数据渲染文章/笔记详情，包含返回入口、元信息、标签、正文排版和“来自内容仓库”的路径提示。
对不存在的 slug 显示 404/未找到状态，不依赖后端。
代码组织
src/components/：布局、导航、内容卡片、筛选栏、终端装饰等可复用组件。
src/pages/：Home、Blog、Notes、ArticleDetail、NotFound 页面。
src/data/：本地 mock 内容及站点配置；后续可替换为 Git 内容解析/API 适配层。
src/lib/：筛选、搜索、slug 查找等纯前端工具。
src/index.css 与 Tailwind 配置：全局字体、颜色变量、滚动条和少量必要的基础样式。
验证
安装依赖后运行开发构建/生产构建检查。
验证三栏导航、详情跳转、搜索、标签筛选、404 状态和移动端布局。
最终说明启动命令及未来接入 Git 内容仓库时需要替换的位置。
