# Glyph Motion Lab

这是一个无依赖的 ASCII/Glyph 动态效果原型，直接打开 `index.html` 即可运行。

渲染管线：

1. 以网格单元采样亮度（示例中用动画波形模拟视频源）。
2. 在 linear-light Y 空间按四个阈值量化到字符等级。
3. 用真实的 5×5 字符资产（米拷贝、米、日、X、田、窗）作为 alpha 形状，再乘上连续的 HSL 颜色场；画布和下方审计卡片共用同一套图案。
4. 加入轻微时域变化与噪声，模拟视频帧间的闪烁和拖影。

真实项目接入视频时，把 `draw()` 中的 `lum` 替换为 `ImageData` 采样即可；如果输入是 sRGB，先用 `pow(channel, 2.2)` 转到线性空间，合成后再用 `pow(value, 1/2.2)` 转回显示空间。
